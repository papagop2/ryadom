# Снимки справочного каталога

## 2ГИС

`slyudyanka-2gis.json` — снимок публичных карточек 2ГИС по Слюдянке и
населённым пунктам Слюдянского района, собранный 20.11.2026. В нём **518
организаций**, контакты, часы, рубрики, рейтинг, **7 845** доступных отзывов
и **8 737** фотографий. Полные списки отзывов остаются на странице 2ГИС —
в приложении всегда есть ссылка на неё.

Сначала были собраны 293 карточки Слюдянки. Затем по карте района добавлены
225 карточек Байкальска, Култука, Утулика, Порта Байкал, Новоснежной и
Мурино; у них отдельные ссылки на городской проект 2ГИС. Дубли с уже
сохранёнными карточками отброшены по `id`, названию, адресу и расстоянию.

Импорт: `node db/import-2gis.mjs` (идемпотентно). Для другого города:

```bash
node db/import-2gis.mjs --city=baikal --name=Байкальск \
  --region="Иркутская область" --lat=51.514 --lng=104.143 \
  --file=db/data/baikal-2gis.json
```

Формат записи: `id`, `name`, `address`, `district`, `lat`, `lng`,
`rubrics[]`, `phones[]`, `sites[]`, `schedule`, `rating`, `ratingCount`, `url`,
`image` (обложка), `photos[] {small,large,full,author}`, `reviews[]
{author,text}`. URL фотографий ведут на публичный фотохостинг 2ГИС; приложение
показывает их с подписью источника.

## OpenStreetMap

`slyudyansky-osm.json` — **362 организации**, которых нет в снимке 2ГИС.
Собраны через Overpass API по административной границе Слюдянского района
(relation `1104970`), адреса уточнены обратным геокодированием Nominatim.
В файле только справочные поля: название, адрес, населённый пункт, рубрика,
телефон/сайт/часы, если они есть в OSM, координаты и ссылка на объект.
Лицензия данных — **ODbL 1.0**, в карточке обязательна подпись
«OpenStreetMap» и ссылка на исходный объект.

Импорт: `node db/import-osm.mjs` (идемпотентно, не удаляет карточки 2ГИС).
Повторный импорт обновляет записи по `source_id = osm:<type>/<id>`.

## Что важно

- Данные и отзывы 2ГИС показываются с подписью «2ГИС» и ссылкой на исходную
  карточку. Данные OSM — с подписью «OpenStreetMap» и лицензией ODbL.
  Приложение не выдаёт их за собственный каталог.
- Свои отзывы аккаунта «Рядом» хранятся отдельно (`reviews.source='own'`),
  проходят модерацию и не меняют рейтинг 2ГИС.
- Снимки статические. Для обновления нужно заново собрать JSON и запустить
  импорт; свои отзывы не затрагиваются. Фотографии не скачиваются в
  репозиторий, а подгружаются по URL; при недоступности CDN карточка
  откатывается к иконке.
- Это не официальный API 2ГИС. Перед публичным запуском проверьте условия
  использования 2ГИС и при необходимости перейдите на официальный API/выгрузку.
  Для OSM сохраняйте атрибуцию и условия ODbL.
