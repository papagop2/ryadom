# Снимок каталога 2ГИС

`slyudyanka-2gis.json` — снимок публичных карточек 2ГИС по Слюдянке, собранный
19.11.2026. В нём 293 организации, контакты, часы, рубрики, рейтинг и 2 970
первых доступных отзывов. Полные списки отзывов остаются на странице 2ГИС —
в приложении всегда есть ссылка на неё.

Импорт: `node db/import-2gis.mjs` (идемпотентно). Для другого города:

```bash
node db/import-2gis.mjs --city=baikal --name=Байкальск \
  --region="Иркутская область" --lat=51.514 --lng=104.143 \
  --file=db/data/baikal-2gis.json
```

Формат записи: `id`, `name`, `address`, `lat`, `lng`, `rubrics[]`, `phones[]`,
`sites[]`, `schedule`, `rating`, `ratingCount`, `url`, `reviews[]
{author,text}`.

## Что важно

- Данные и отзывы показываются с подписью «2ГИС» и ссылкой на исходную
  карточку. Приложение не выдаёт их за собственный каталог.
- Свои отзывы аккаунта «Рядом» хранятся отдельно (`reviews.source='own'`),
  проходят модерацию и не меняют рейтинг 2ГИС.
- Снимок статический. Для обновления нужно заново собрать JSON и запустить
  импорт; старые отзывы не удаляются.
- Это не официальный API 2ГИС. Перед публичным запуском проверьте условия
  использования 2ГИС и при необходимости перейдите на официальный API/выгрузку.
