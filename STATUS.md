## Как запустить на ПК №2 (после установки PostgreSQL)

1. Создать БД и роли (пример, от суперпользователя `postgres`): `create role rjadom_app login password '<пароль>';` и `create database rjadom owner rjadom_migrator;`. Роль приложения получает только DML в схеме `public`, без владения.
2. Задать переменные окружения `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD` (см. `.env.example`); пароли хранить вне папки проекта.
3. `npm.cmd run migrate` — применяет `db/migrations/*.sql`, журнал в `schema_migrations`.
4. `npm.cmd run seed` — демоданные; повторный запуск не дублирует, `npm.cmd run db:reset` сбрасывает каталог.
5. `npm.cmd run api` — API на `127.0.0.1:3100`; при `DEMO_LOGIN=1` код входа возвращается в ответе и показывается в интерфейсе.
6. `npm.cmd run build`, `npm.cmd test`, `npm.cmd run smoke` — сборка, тесты и проверка собранной PWA с API на loopback.

Демо-телефоны после `npm.cmd run seed`: клиент `+79000000001`, партнёр `+79000000002` (студия «Форма»), оператор `+79000000003`. Любой другой номер тоже входит как клиент.
