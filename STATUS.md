## Как запустить на ПК №2

PostgreSQL 16 уже установлен и настроен. Переменные окружения лежат в `C:\Users\User\Desktop\netral2\secrets\rjadom.env` (приложение) и `rjadom-host.env` (HTTPS-служба); в репозиторий они не попадают.

1. Миграции выполняются ролью-владельцем: `PGUSER=rjadom_migrator PGPASSWORD=<из secrets> node db/migrate.mjs` (или теми же значениями через `npm.cmd run migrate`).
2. `node db/seed.mjs` — демоданные; повторный запуск не дублирует каталог, `node db/seed.mjs --reset` сбрасывает его.
3. `node --test tests/*.test.mjs` — тесты на живой БД; тесты сами применяют миграции ролью мигратора (`PGMIGRATOR_USER`/`PGMIGRATOR_PASSWORD`) и сид приложением.
4. `node tests/smoke.mjs` — собранная PWA и API на loopback; занимает порты 3100 и 4173.
5. Служба стенда: `C:\Users\User\Desktop\netral2\service\rjadom-host.exe` (`status`, `restart`, `stop`) либо `Restart-Service rjadom-host` от администратора. Журналы — `C:\Users\User\Desktop\netral2\logs\rjadom-host.out.log`.
6. Адреса стенда: `https://app.home.arpa/` (нужен локальный DNS) и `https://192-168-50-150.sslip.io/` (публичный DNS указывает на LAN-адрес); сертификат — `secrets\rjadom-tls.cer`. API напрямую наружу не публикуется, PostgreSQL слушает только `127.0.0.1:5432`.

Демо-телефоны после сида: клиент `+79000000001`, партнёр `+79000000002` (студия «Форма»), оператор `+79000000003`, водитель `+79000000004` (Kia Rio, A123ВС77), курьер `+79000000005` (Курьер Демо). Любой другой номер тоже входит как клиент.
